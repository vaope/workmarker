# WorkEventAgent v0.1.3

## 改进

- **快捷输入更可靠**：兼容 opencode 返回多段文本、Markdown JSON 代码块、说明文字包裹 JSON，以及被拆分到多个片段中的 JSON，减少不同电脑或模型配置下的结构化解析失败。
- **记录保留更多原始信息**：归档时以用户输入为权威来源，避免摘要遗漏技术名称、输入输出、约束条件和后续条目。

## 修复

- 修复主窗口在显示、恢复、缩放或调整大小后偶发只渲染上半部分的问题。

## 兼容性

- 无需迁移现有项目数据。
- 仍需本机安装并配置可用的 Python 与 opencode CLI。
